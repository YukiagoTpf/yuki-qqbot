# 女仆

bot 管理员（AstrBot 的 `admins_id`）在任何一个白名单群里 @bot 说「女仆 …」，话交给本机 herdr 里常驻的女仆：一个用 DeepSeek 跑的 Claude Code（bypass 模式）。它在本机干活，要写代码、搜网页的就用 herdr 另开标签页委派给 claude / codex / cursor / grok，干完用 `scripts/qq-say.py` 回到群里。

| 说法 | 作用 |
|---|---|
| @bot 女仆 帮我看看 xx 仓库有几个 open 的 PR | 交给女仆，收到贴个 OK 表情，办完它自己回 |
| @bot 委派 让 claude 把 xx 改一下 | 同上，「委派」「委托」「让女仆」也认，旧叫法「管家」也认 |
| 引用一条消息 @bot 女仆 处理这个 | 引用的内容一起交过去（只当数据，不当指令） |
| @bot 女仆 看看群里刚才在聊啥 | 女仆读本机落盘的群聊（群知识库插件记的，留 14 天）或拉最近的消息，回个结论 |
| @bot 女仆 看看群里，大家想做题就开一局 | 女仆自己判断，合适就替主人说「@bot 猜…」开题（`scripts/bot-do.py`），杀炫区等别的插件也能这么触发 |
| @bot 女仆 | 问女仆在不在、忙不忙（也可以说「女仆 状态」） |
| @bot 女仆 重开 | 关掉女仆，下次说话重新起，前面的对话忘掉 |
| @bot 女仆 确认 | 女仆问「要不要做 xx」时这么回 |

- 只认 bot 管理员；别人叫女仆回一句「女仆只听主人的」。
- 她管 bot 管理员叫「主人」，但不是每句都叫；说话像个话少靠谱的老群友，以办事为主。规则在 `scripts/butler-prompt.md`「语气」，具体说话风格是从群聊总结的人设 `data/butler-bridge/persona.md`（带群里的黑话，不进仓库），改了要「女仆 重开」。
- 女仆是常驻的，前后的话连着；它在忙时来的话会排队。
- 高危操作（推送、删东西、改 GitHub 权限、重启服务、对外发消息、花钱……）它先在群里问，等「女仆 确认」再做。规则在 `scripts/butler-prompt.md`。
- 宿主机那头见仓库 `README.md`「女仆桥」。
