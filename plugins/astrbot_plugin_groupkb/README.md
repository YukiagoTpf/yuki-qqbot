# 群知识库

把生效群的聊天记到本地，每天凌晨让 LLM 读一遍前一天的聊天，往按群的知识库 `groups.yaml`（AstrBot 数据目录下，宿主机上是 `data/astrbot/groups.yaml`）里加三样东西：

- `members`：群友在群名片以外的外号，按 QQ 号记。杀炫区判定时用它认出打字里提到的是谁。
- `notes`：这个群特有、会反复用到的黑话、梗、规矩。杀炫区判定时整段交给模型。
- `events`：当天值得留档的事，按日期存，最多 `events_per_day` 件。只是留档，不给别的插件用。

不在群里说话，没有指令。

## 落盘

生效群（`groups`）的每条消息都记，包括 bot 自己发的：插件数据目录的 `chat/<群号>/<YYYY-MM-DD>.jsonl`，一行一条，只留文字、@、引用、表情的字面，图片只记是图（链接会过期）。留 `keep_days` 天。消息处理优先级设得最高、从不拦截，别的插件截住的指令（「猜游戏」）也记得到。

## 每天的整理

过了 `run_at`（默认 04:00）就整理昨天的；电脑睡过了点，醒来补，最多补 3 天。整理到哪天记在插件数据目录的 `state.json`。模型出错隔一小时再试，同一天失败 3 次跳过。

1. 落盘的记录加上 NapCat 的历史（`get_group_msg_history` 拉 3000 条，大约两天），按消息 id 去重，补上 AstrBot 重启那几秒漏记的。少于 30 条的日子不整理。
2. 渲染成「HH:MM 代号：内容」，代号 P1、P2……，附一张代号表（群名片）。给模型看群名片（认外号要靠它），不给 QQ 号；模型说的代号由程序换回 QQ 号存，写进黑话、留档里的代号换回群名片。
3. 每 500 条一段，让模型挑外号（要有证据）、黑话、有意思的事（`core/prompts.py` 的 `EXTRACT_SYSTEM`）。DeepSeek 的内容审核拦了就对半拆开重试，拆到很短还拦就跳过那段。
4. 各段挑出来的事再汇总一次（`DIGEST_SYSTEM`）：合并重复的，挑最多 `events_per_day` 件；新黑话去重，一天最多加 3 条。
5. 重新读一遍 `groups.yaml`（整理要几分钟，期间可能有人手改了），往里加：
   - 外号：当天原话里至少出现 2 次、不是他群名片的一部分、没记给别人的才记。只出现一次的多半拿不准在叫谁。
   - 黑话：和已有的不重复，总数到 `max_notes`（默认 20）就不再加。
   - 留档：当天那段整个替换，重跑同一天不会叠两份。

只加不删：自动加错的外号、黑话直接在文件里删掉。文件开头的注释每次重写，数据都保留。写的时候先写临时文件再替换，杀炫区随时在读，不会读到半截的。

2026-11-07 用前一天的真实聊天（2007 条）试过：开思考，5 段加汇总约 7 分钟。第一版漏了代号（「调侃 P17……」），一天加了 9 条「黑话」，混着 bot 的功能说明和一次性玩笑；收紧以后加了 1 条，外号 4 个，留档 5 件。
